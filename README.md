## Project Overview

This project analyses Melt Gelato's historical sales data to understand customer demand, identify best-selling products, and support better inventory and staffing decisions.

## Tools Used

- Python (Pandas, NumPy, Matplotlib, Scikit-learn)
- Power BI
- Excel
- Open-Meteo Historical Weather Data

## Analysis Performed

- Data cleaning and exploratory analysis
- Monthly, weekly, and hourly sales trends
- Product performance and ABC classification
- Weather and sales correlation analysis
- Market basket analysis
- Sales forecasting and model comparison

## Key Findings

- Weekend sales were 53.95% higher than weekday sales.
- Peak trading hour was 8 PM.
- 44 products contributed 80.45% of payment revenue.
- Calendar Ridge achieved the lowest forecasting error (12.74% WAPE).

## Recommendations

The findings support improved staff scheduling, prioritised inventory management, and better preparation for peak trading periods.
